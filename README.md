# JugaPlatform

**JugaPlatform** — мобильная endless-runner игра для Android (Kotlin + Jetpack Compose), вдохновленная Chrome Dino, но с латиноамериканским вайбом.

## Концепт

- Герой: **JUGADOR-MAN** (испанский стиль имени для JUGA+MAN).
- Локация: стилизованные пейзажи Латинской Америки (Анды, солнце, облака, пустынная тропа).
- Геймплей: тап по экрану = прыжок. Нужно избегать препятствий:
  - кактусы,
  - ламы,
  - баррикады.
- Прогресс: очки, дистанция в метрах, лучший рекорд.

## Технически

- Android Studio-проект с модулем `app`.
- Язык: Kotlin.
- UI/рендер: Jetpack Compose + `Canvas`.
- Без бинарных картинок: все визуальные элементы рисуются кодом (векторная/процедурная графика).

## Запуск

1. Открыть папку проекта в Android Studio.
2. Дождаться sync Gradle.
3. Запустить на эмуляторе или реальном Android-устройстве.

## Управление

- Первый тап запускает игру.
- Во время игры каждый тап делает прыжок.
- После поражения нажать **Reintentar** для рестарта.
